## 📌 About

A product list and a page for each product, plus a contact page, fed by Origamid's Ranek API. Built in Origamid's **React** course.

## 🧠 What I practiced

- **Routing with params** to open each product by its id.
- **Fetching data** and showing loading and error states.
- **CSS Modules** and per-page titles.

## 🚀 Run locally

You need Node.js and Yarn (or npm).

```bash
git clone https://github.com/wanderson1873/Loja.git
```

Runs on `http://localhost:3000`:

```bash
cd Loja/web
yarn install
yarn start
```
